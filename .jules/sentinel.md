## 2026-08-30 - [SSRF Validation Missing on Some URL Fields]
**Vulnerability:** Several Pydantic models in `src/coreason_manifest/spec/ontology.py` containing `AnyUrl` or `HttpUrl` fields (like `target_registry_uri`, `linkml_schema_uri`, `schema_registry_uri`, `shacl_shape_graph_uri`, `base_uri_namespace`, `async_observation_port`, and `canonical_uri`) were missing the SSRF (Server-Side Request Forgery) safety validator `_enforce_ssrf`.
**Learning:** Even though SSRF validation existed and was applied to some fields (like transport endpoints), it wasn't systematically applied across all dynamically resolved external URI fields, which could allow a malicious actor to inject internal loopback or private network URLs for tasks like schema discovery, RDF exports, or ontology polling.
**Prevention:** Always verify all `AnyUrl` or `HttpUrl` fields across a declarative API boundary to ensure SSRF protections are universally applied, particularly in data-plane configurations dealing with external registries or asynchronous observation ports.
