## 2025-05-15 - Caching Numpy Computations on Base64 Vectors
**Learning:** In a codebase that handles large vector embeddings inside Pydantic/dataclass structures initialized via base64, calculating distances involves three steps: `base64_decode`, `np.frombuffer`, and `np.linalg.norm`. Because the input base64 string is immutable and perfectly hashable, wrapping the decoding and norm calculation with `@functools.lru_cache` provides a >10x speedup for repeated comparisons. Using `np.frombuffer` on `bytes` creates read-only arrays, ensuring cache safety.
**Action:** Use `lru_cache` keyed on the base64 string for operations converting serialized byte data into dense Numpy arrays or computing static vector features. When doing this, mock the `__wrapped__` version in edge-case tests to prevent the cache from short-circuiting identity checks (`is`) used in test setups.
